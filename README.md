# Python Learning Notebooks Overview

This README provides a summary of the content and code in each of the 7 Jupyter notebooks in this repository. Each notebook covers a fundamental topic in Python programming, with code examples and explanations.

---

## 1. 1-Basics.ipynb
**Topic:** Basic Python Syntax and Operations
- Introduction to Python variables and basic operations
- Printing values and simple arithmetic
- String assignment and output
- Notebook cell shortcuts and usage tips

---

## 2. 2-DataStructures.ipynb
**Topic:** Data Structures
- Overview of Python data structures: Lists, Tuples, Sets, Dictionaries
- List indexing, slicing, and iteration
- Example code for manipulating and accessing elements in lists
- Introduction to properties of each data structure (ordered, unordered, mutable, immutable)

---

## 3. 3-Conditional.ipynb
**Topic:** Conditional Statements
- Using `if`, `elif`, and `else` for decision making
- Example: Voting eligibility based on age
- Example: Grading system based on marks
- Activities for practicing conditional logic

---

## 4. 4-FunctionsOOPs.ipynb
**Topic:** Functions and Introduction to OOP
- Defining and calling functions in Python
- Function arguments and return values
- Example: Greeting function, cube calculation
- Introduction to Object-Oriented Programming (OOP) concepts

---

## 5. 5-Class.ipynb
**Topic:** Classes and Objects
- Defining classes and methods
- The `__init__` constructor method
- Example classes: `Person`, `Dog` with attributes and methods
- Explanation of class vs. instance attributes

---

## 6. 6-FileHandling.ipynb
**Topic:** File Handling
- Opening, reading, writing, and closing files in Python
- Reading entire files, single lines, and all lines as a list
- Writing single and multiple lines to a file
- Using different file modes: read (`r`), write (`w`), append (`a`)
- Example code for file operations on `example.txt`

---

## 7. 7-ErrorHandling.ipynb
**Topic:** Error Handling
- Using `try`, `except`, and `finally` blocks
- Handling `FileNotFoundError` when working with files
- Ensuring files are properly closed using `with` statements
- Example: Prompting user for a file name and handling errors gracefully

---

Each notebook is designed to be self-contained and includes both code and explanatory markdown cells. Together, they provide a practical introduction to Python programming, from basics to file and error handling.
